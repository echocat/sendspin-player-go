# Independent Noise oracle vectors

The offline unit test `TestIndependentCacophonyKKpsk2Vectors` uses fixed expected
bytes from the independent Haskell implementation **Cacophony**, not expected
ciphertext generated by this Go SDK or its `flynn/noise` dependency.

- Repository revision: `8ee9d41e34a1a596cfa3ab12aa4069ff87dc1247`.
- Source: `vectors/cacophony.txt`, Git blob
  `b8a271ed1aba8b4a56bf429e559d7947827123b4`.
- Full source SHA-256:
  `3bde7c09a6f349ee11c825c50fcc02649f8f02a47c857a459206b357f9386cae`.
- Frozen subset: `internal/wire/testdata/cacophony.json`, both
  `Noise_KKpsk2_25519_{AESGCM,ChaChaPoly}_SHA256` records.
- License: public domain/Unlicense; the text is retained with the fixture.

Each record supplies two handshake messages, final handshake hash, and four
alternating transport messages. Tests check the responder's exact message-2
ciphertext, key direction, nonce progression and every transport payload/byte.
Replay, out-of-order, tamper, reversed direction, wrong PSK and wrong prologue
are independently tested against those frozen values. Failed primitive decrypts
must not consume a nonce; the SDK's separate handler tests enforce connection
closure, rather than continuing after an authentication failure.

Deterministic private keys/ephemerals here are **published test inputs only**.
Production still constructs fresh responder handshakes with `crypto/rand.Reader`;
its source-policy guard rejects configured/reused ephemeral material. The vector
payloads/prologue are those of the foreign oracle, not Sendspin application JSON.
Therefore this is primitive/configuration compatibility evidence, not a test of
the RC1 init envelope or a proof of forward secrecy.

```text
mise run audit:verify-noise
```

This explicit network check fetches the exact immutable source, verifies SHA-256
and Git blob, and compares the subset plus both peers' PSK/static/ephemeral/prologue
inputs. Unit tests remain offline. Changed pins, extraction, transcript, missing
suites or unavailable source fail closed. The full gate and existing traceability
job run this check; PortAudio CI is unchanged.

The [source security review](cryptographic-review.md) and CN19.04 retain their
separate assurance limits. These finite vectors do not certify the primitive or
replace an independent cryptographic security audit.
